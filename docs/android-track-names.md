# Названия аудиодорожек Android/TV

В меню «Настройки → Аудио» нативного плеера Media3 показывается `Format.label`
из контейнера: название озвучки, студии или другой заголовок дорожки. Рядом
сохраняются локализованные язык, каналы и битрейт стандартного Media3.
Например, две русские дорожки 5.1 можно различить по LostFilm и AlexFilm.
Если подпись отсутствует, сохраняется стандартное описание. Название группы
не угадывается по имени файла или раздачи.

В Media3 1.11.1 встроенный `PlayerControlView` не предоставляет setter для
`TrackNameProvider`. Поэтому кнопка настроек открывает небольшой системный
диалог с теми же разделами скорости и аудио. Используются только публичные
API Media3, без reflection и копирования классов библиотеки. Субтитры остаются
в стандартном меню. Список дорожек прокручивается и доступен с D-pad.

Выбор аудио меняет только override аудиодорожки. «Авто» очищает только аудио
и возвращает автоматический выбор. Неподдерживаемые дорожки не предлагаются;
при смене плеера или списка дорожек устаревший выбор не применяется. При
закрытии Activity диалог закрывается. Меню работает и на mobile, и на TV.
