# Предпочитаемый язык аудио

При English в настройках FreeScene нативный и веб-плееры предпочитают
поддерживаемую английскую дорожку, затем явно обозначенную оригинальную.
Ручной выбор имеет приоритет. Неизвестный язык, первая дорожка и флаг default
не считаются признаком английского или оригинала. Код языка важнее имени;
среди дорожек одного языка основная озвучка предпочтительнее комментариев.

macOS использует снимок языка FreeScene при открытии источника и метаданные
libVLC после появления дорожек. Android получает язык приложения через канал
и использует только дорожки, поддерживаемые Media3. Новая серия пересчитывает
выбор; индекс из предыдущего файла не переносится. Русский режим сохраняет
обычный выбор движка. Субтитры отдельно не переключаются.

Веб-мост получает то же предпочтение при открытии страницы. Общий скрипт
`assets/player/audio_preference.js` работает с доступным `audioTracks`, включая
поздние дорожки и вложенные фреймы. Собственные события автоматического выбора
отличаются от последующих изменений со стороны пользователя/провайдера.
Ручная команда FreeScene также отключает автоподбор для текущего источника.
Если список недоступен, воспроизведение продолжается; меню аудио предлагает
открыть управление провайдера. На macOS этот пункт переключает панель обратно
на управление провайдера. Смена языка интерфейса сайта не используется как
способ переключения аудио.

## Поддержка источников

Для локальных файлов, торрентов и прямых видеопотоков FreeScene использует
метаданные дорожек libVLC или Media3. Во встроенном веб-плеере FreeScene
проверяет доступность `audioTracks` во время воспроизведения. Если сайт
сам управляет дорожками и скрывает их от приложения, зритель выбирает
озвучку в меню сайта.

Проверки: `tests/web/audio_preference.mjs`, Android `AudioPreferenceTest`,
`tests/native/run_audio_preference.py` (настоящие файлы с несколькими дорожками
через libVLC), `tests/native/run_web_controls.py` (WebKit, включая вложенные
и динамические фреймы). Для запуска нативных тестов нужны подготовленные
библиотеки в `build/native`.
