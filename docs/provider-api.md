# Контракт провайдеров

`packages/freescene_provider_api` содержит готовые карточки, источники,
фильтры, дескрипторы, запросы воспроизведения, трейлеры и общий HLS-транспорт.
В нём нет адресов сайтов, парсеров их выдачи или словарей конкретного каталога.
`runFreeScene(providers: setup)` устанавливает конфигурацию до чтения профиля.
Публичный `lib/main.dart` подключает `lib/providers/demo.dart`.

`CatalogRepository` выполняет поиск, выдачу, детали и получение источников.
`playback` возвращает разрешённый URL, тип плеера, MIME, referrer и выбранную
серию. UI отображает возможности `ProviderDescriptor`, не сравнивает имена
сайтов. Данные фильтров приходят через `loadDictionaries`.

`SourceProvider` — строковый ID со сравнением по значению. Неизвестные ID
сохраняются в настройках и загрузках. Стабильные ID карточек и ключи истории
не переименовываются. Парсинг внешнего JSON находится в адаптерах;
`CatalogTrailer.fromJson` читает только локальный формат и сохраняет ссылки
неизвестных провайдеров. Зарегистрированный адаптер проверяет известные ID.

`freescene_provider_host` задаёт нативный контракт сессии и веб-плеера.
Android и macOS получают от подключённого адаптера правила адресов,
анонимную сессию, скрипт выбора видео и навигационные ограничения.
Плеер владеет UI, масштабом, полноэкранным режимом и каналом прогресса.
Веб-страница передаёт только время для открытого сеанса и не выбирает ключ
записи истории. Без зарегистрированного адаптера веб-переход отклоняется.

Публичное приложение не содержит обязательной закрытой зависимости.
Сборщик официального приложения экспортирует закреплённые ревизии, добавляет
path-зависимость только во временный pubspec и заменяет точку входа. Копий
или патчей интерфейса в модуле провайдеров нет. Версия контракта — 1.0.0.
