# Продолжение просмотра на Android и TV

Нативный плеер и встроенные веб-плееры провайдеров сохраняют позицию в
приватных настройках приложения. При повторном открытии появляется диалог
«Начать просмотр сначала или продолжить?» с сохранённым временем. «Сначала»
сбрасывает отметку; отмена закрывает просмотр, сохраняя её. После завершения
видео отметка удаляется. Прямые трансляции не сохраняются.

История ограничена 200 видео. Для прямых источников используется постоянный
идентификатор каталога, для веб-плееров — страница фильма или серии, для
торрентов — хеш и индекс файла. Адаптер может задать общий ключ для нативного и веб-воспроизведения. В торренте запоминается также последний открытый файл.
Серии хранят отдельные позиции. Временные CDN-ссылки не заменяют идентификатор.

Media3 сохраняет позицию каждые пять секунд, при смене файла и уходе с экрана.
Веб-скрипт передаёт позицию примерно раз в секунду, при паузе и завершении;
запоздалые сообщения закрытой страницы не применяются. Вложенные плееры
подключаются только внутри выбранного адаптером блока. Передаётся только время
текущего сеанса: веб-страница не может указать ключ истории или прочитать другие
отметки. Временные значения проверяются в нативном коде.

Для вложенных фреймов разных доменов нужен WebView с `DOCUMENT_START_SCRIPT`.
В старом WebView остаётся поддержка HTML5-видео основного документа. Сторонние
плееры без доступного HTML5-видео и реальные аппаратные декодеры не покрыты
проверкой веб-скрипта.

Проверки:

```sh
cd android
./gradlew :app:testTvDebugUnitTest :app:testMobileDebugUnitTest --tests '*PlaybackHistoryTest' --tests '*PlayerWindowTest' --tests '*WebPlayerTest' --tests '*TorrentPlayerTest'
cd ..
xcrun clang++ -fobjc-arc -framework Cocoa -framework WebKit tests/native/player_progress.mm -o build/player-progress-test
build/player-progress-test
```

Robolectric проверяет хранилище, диалог, смену серии, отмену, таймеры, фокус и
системные панели. WebKit исполняет настоящий скрипт с управляемыми часами видео
в изолированном iframe, включая позднее появление видео и однократный переход
к сохранённому времени. Эта проверка не загружает провайдеров и не проверяет
декодирование на физическом Android-устройстве.
