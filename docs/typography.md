# Шрифт FreeScene — Play

Интерфейс использует **Play**: Regular (400) для текста и Bold (700) для заголовков. Оба начертания содержат кириллицу. Flutter подключает семейство через `pubspec.yaml`; подписи и меню AppKit-плеера используют тот же Regular через CoreText. Системные заголовки окон и меню macOS сохраняют системную типографику. Шрифт не устанавливается в систему.

Исходные файлы включены без изменений из официального Google Fonts: https://github.com/google/fonts/tree/51c6a423fbfbd78a5111241dfd07791644b4c5c6/ofl/play. Происхождение и SHA-256 зафиксированы в `validation/freescene/play-fonts.json`.

Лицензия **SIL Open Font License 1.1** сохранена в `licenses/Play-OFL.txt` и доступна в экране лицензий FreeScene. Для локальной сборки дополнительные файлы не нужны. Официальная лицензия: https://raw.githubusercontent.com/google/fonts/main/ofl/play/OFL.txt.
