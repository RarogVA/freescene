# Оформление FreeScene

Тёмная тема использует «Графит + медь», светлая — «Фарфор + индиго». Переключение и сохранение выбора работают через существующую настройку темы.

| Роль | Тёмная | Светлая |
| --- | --- | --- |
| Фон | `#17181B` | `#F4F3F0` |
| Панели | `#222429` | `#EAE9E5` |
| Приподнятая поверхность | `#2C2E34` | `#FFFFFF` |
| Основной текст | `#EEEEF0` | `#252731` |
| Вторичный текст | `#A7A8B0` | `#5D606C` |
| Акцент | `#DDA66C` | `#5263C7` |
| Выделенная строка | `#393127` | `#DCE0F4` |

Вторичный текст светлой темы и текст на выделенной строке затемнены для контраста не менее 4,5:1. Нейтральные поверхности Material заданы явно, чтобы меню, таблицы и диалоги не наследовали прежний синий оттенок. Ошибки сохраняют отдельный красный цвет. Шрифт Play и геометрия интерфейса сохранены.

Общая Flutter-палитра находится в `lib/theme/freescene_theme.dart`, нативные роли macOS — в `macos/Native/FSTheme.h`. Плеер, встроенные веб-плееры, окно «О приложении», лицензии и выбор файла согласованы с каталогом. Android-видеоплееры сохраняют тёмную подложку с нейтральными элементами и медным фокусом. Android TV сохраняет серую заливку выбранной категории отдельно от рамки фокуса пульта.

## Иконка F

Выбранная иконка: объёмная медная F из сложенной ленты на графитовой плитке. Исходник `assets/branding/app-icon.png` — PNG 1254 × 1254 с прозрачностью вне плитки. Он используется в интерфейсе и для генерации иконок macOS, Android и Android TV, включая TV-баннер. Лицензия ассета сохранена в `assets/branding/LICENSE.txt`.

Для изменения размеров исходной иконки без перерисовки:

```sh
python3 tools/generate_app_icons.py
```

Скрипт использует штатный `sips` в macOS и сохраняет альфа-канал. Иконка строки меню остаётся монохромным template-знаком F, автоматически окрашиваемым macOS.
