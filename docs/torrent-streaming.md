# Торрент и воспроизведение

- libtorrent-rasterbar 2.1.2 в процессе приложения, отдельные нативные очереди. Dart получает только команды и снимки состояния.
- Добавление локального `.torrent` и magnet, получение metadata BEP 9, пауза/продолжение, очередь, лимиты скорости и числа активных загрузок.
- Исходный провайдер сохраняется отдельно от состояния. Повторное добавление infohash сохраняет происхождение первой задачи, включая совпадения v1/v2 гибридных раздач.
- Сиды и пиры — разные виды установленных BitTorrent-подключений; web seeds и соединения на стадии handshake в эти числа не входят. На паузе/в очереди отображается «—».
- Сессия и metadata сохраняются через `save_resume_data`; состояние очереди, провайдер и лимиты переживают перезапуск. Профиль блокируется от одновременной записи двумя экземплярами приложения.
- Локальный HTTP на случайном порту `127.0.0.1`, непредсказуемый токен URL, GET/HEAD, одиночные byte ranges, суффиксы и ответ 416 для некорректных диапазонов.
- Приоритеты кусков вокруг позиции чтения задаются через `set_piece_deadline`; окна нескольких HTTP-запросов объединяются, ненужные deadlines снимаются. Данные читаются через `read_piece` и соответствующий alert; на диск с незагруженными участками шлюз напрямую не обращается. Кэш проверенных кусков ограничен 32 МиБ плюс буферы активных ответов.
- Ожидание первого куска — до 90 с, следующего — до 45 с. Пауза плеера останавливает этот отсчёт; медленное чтение готовых данных не обрывает HTTP-ответ. Прямого доступа к произвольным путям HTTP-шлюз не предоставляет.
- Отдельное окно AppKit/libVLC: локальные видео, недокачанный выбранный видеофайл, выбор файла многосерийной раздачи, пауза, повтор, позиция, native fullscreen, аудиодорожки/субтитры, автоматическое скрытие панели. Щелчки и жесты обрабатываются нативно. Закрытие плеера не удаляет загрузку.
- Системные события подключены к четырём переключателям через NotificationGate. Разрешение macOS запрашивается при первом запуске; в блоке уведомлений доступна кнопка с иконкой колокольчика. Ошибка остаётся в загрузках независимо от разрешения баннеров.

Профиль движка — `~/Library/Application Support/FreeScene/torrents`; загрузки — `~/Downloads/FreeScene/<infohash>/`. Переменные `FREESCENE_DATA` и `FREESCENE_DOWNLOADS` задают изолированные каталоги. `FREESCENE_TEST_MODE=1` отключает DHT/LSD и ограничивает транспорт loopback; используется только тестами, в обычном запуске не выставляется.

Приватные торренты сохраняют свои трекеры; внешние трекеры им не добавляются. libtorrent намеренно не отдаёт BEP 9 metadata приватных раздач: интеграционный тест magnet использует публичный формат метаданных при полностью локальном транспорте.

## Жизненный цикл

Ожидание metadata и запуск просмотра находятся в контроллере приложения.
Закрытие плеера отменяет ожидающий запуск; поздний ответ движка не открывает
окно повторно. Загрузка и история сохраняются независимо от состояния окна.

Кнопки панели и системные кнопки окна исключены из перехвата жестов видео.
Показ скрытой панели не переключает воспроизведение. Анимация ожидания и
статистика строятся по снимкам движка; при паузе или ошибке анимация останавливается.

Нативные проверки геометрии и жизненного цикла находятся в `tests/native/`.
Состав библиотек и порядок пересборки описаны в [документации VLC](vlc-distribution.md).
