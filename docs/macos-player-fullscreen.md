# Окно-заглушка плеера при переключении рабочих столов macOS

При полноэкранном видео WebKit переносит `WKWebView` в отдельное окно, оставляя заглушку в исходном плеере. При свайпе между рабочими столами пользователь видел это пустое окно с надписью «Click to Exit Full Screen». Сам фильм оставался в другом Space. [Описание поведения в WebKit](https://github.com/WebKit/WebKit/blob/main/Source/WebKit/UIProcess/API/Cocoa/WKWebView.h).

`FSWebFullscreen` наблюдает публичное свойство `fullscreenState`. Исходное окно скрывается только после завершения перехода WebKit и только если веб-представление действительно оказалось в другом окне. Обычный полноэкранный режим зелёной кнопкой macOS не скрывает окно с видео. Перед обратной анимацией исходный плеер возвращается. Закрытие и смена источника снимают наблюдение, чтобы позднее завершение перехода не возвращало закрытый плеер.

Перед удалением веб-представления из полноэкранного окна FreeScene приостанавливает медиа и ожидает завершения `closeAllMediaPresentationsWithCompletionHandler:`. Проверка готовности выбранного плеера сначала проверяет текущую страницу и только затем применяет тайм-аут: задержанный переходом между Spaces таймер не объявляет уже готовый плеер зависшим.

## Проверка

```sh
python3 tests/native/run_web_fullscreen.py
python3 tests/native/run_player_lifecycle.py
python3 tests/native/run_player_lifecycle.py

# Только сборка изолированного приложения для ручной UI-проверки.
python3 tests/native/run_web_fullscreen.py --ui
```

15 проверок полноэкранного жизненного цикла включают обычный macOS fullscreen, перенос WebKit, восстановление окна, прямой выход без промежуточного состояния, скрытое до перехода окно, закрытие и смену контейнера. Проверки настоящего нативного плеера покрывают готовую страницу после истечения 30 секунд, сохранение ошибки для неготовой страницы, игнорирование старого ответа и порядок закрытия/отсоединения WebKit во всех состояниях fullscreen. Проверки трейлеров и смены источника также проходят.

Ручная проверка на Apple Silicon: зелёной кнопкой развёрнуто окно UI-фикстуры, затем локальный HTML-элемент переведён в WebKit fullscreen. Исходное окно стало невидимым, отдельное окно WebKit осталось видимым. После Esc веб-представление вернулось в исходное окно, и его полноэкранный режим macOS сохранился. Фикстура не использует сеть, аккаунты или настоящее видео; воспроизведение конкретного внешнего источника и физический Intel Mac этой проверкой не охвачены.

Исправленные локальные пакеты находятся в `build/fullscreen-fix-arm64` и `build/fullscreen-fix-x86_64`. Они сохраняют базовую версию 1.3.0 (build 36) и не являются файлами опубликованного релиза 1.3.0.
