# Android и Android TV

Общие Dart-модели и UI, нативный Media3-плеер и WebView. Две сборки:
`mobile` (`local.freescene.freescene`) и `tv` (`local.freescene.freescene.tv`).

На телефоне касание активирует кнопку с первого раза. Восстановление
позиции пульта, рамки фокуса и перехват стрелок включены только на TV.
Поля ввода сохраняют обычный клавиатурный фокус. На телефоне круглые кнопки
домой, загрузок и настроек находятся в верхней панели под переключателем
фильмов/сериалов. TV сохраняет навигацию пультом.

При воспроизведении скрываются системные панели. Заголовок и нижние кнопки
плеера используют общий таймер; масштаб находится справа. История
воспроизведения предлагает начать сначала или продолжить. Общий WebView
принимает зарегистрированные правила провайдера через публичный host.

## Сборка и проверки

Flutter 3.47.7, JDK 17, Android SDK, NDK 28.2.13676358. Подробности
декодеров и исходников — [Android audio](android-audio.md).

```sh
flutter pub get
flutter analyze
flutter test
python3 tools/build_android.py --flavor mobile --preview
python3 tools/build_android.py --flavor tv --preview
cd android
./gradlew :app:testTvDebugUnitTest :app:testMobileDebugUnitTest
```

`--preview` использует локальный debug-сертификат. Production `--release`
требует `android/key.properties`; ключи и пароли не входят в Git.
Сохраняйте application ID, flavor, versionCode и сертификат при обновлении.

Публичный checkout запускается с демонстрационным каталогом. Реальные
адаптеры и их интеграционные тесты подключает официальный сборщик отдельно.

## Обновления

Фиксированный источник: `RarogVA/freescene`, без токенов. В «О приложении»
две кнопки: проверка/установка с текущим статусом и лицензии открытого ПО.
Нативный код проверяет имя и ABI APK, размер, SHA-256, версию, package ID
и сертификат. Разрешение установки обрабатывает системный экран Android;
повторное нажатие использует уже проверенный APK. Пока конечный репозиторий
закрыт, анонимная проверка не получает его выпуски.
