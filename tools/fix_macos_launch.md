# Исправить запуск FreeScene

Если macOS не позволяет запустить FreeScene, откройте «Терминал» и выполните
команду:

```sh
xattr -r -c /Applications/FreeScene.app/
```

Команда удаляет расширенные атрибуты, включая карантин, у установленного
приложения. После этого запустите FreeScene из папки «Программы».

Если FreeScene установлен в другую папку, замените путь в команде.
